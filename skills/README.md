# AI Development Skills Library

A comprehensive knowledge base for AI-assisted software development using Django + Next.js stack.

## 📁 Structure Overview

```
skills/
├── system-design/          # System design principles & patterns
├── backend/
│   └── django/            # Django framework expertise
├── frontend/
│   └── nextjs/            # Next.js & React expertise
├── database/              # Database design & optimization
│   ├── postgresql/
│   ├── redis/
│   └── elasticsearch/
├── devops/                # Infrastructure & deployment
│   ├── docker/
│   ├── kubernetes/
│   ├── ci-cd/
│   └── monitoring/
├── architecture/          # Architectural patterns
├── api-design/            # API design principles
├── testing/               # Testing strategies
├── security/              # Security best practices
├── best-practices/        # Coding standards & conventions
└── templates/             # Reusable project templates
```

## 🎯 Usage for LLMs

When working with AI agents:

1. **Reference specific files** for domain expertise
2. **Copy relevant sections** into context for complex tasks
3. **Use templates** as starting points for new features
4. **Follow conventions** documented in best-practices

## 🚀 Quick Start

For a new project, reference:
1. `templates/django-nextjs-project.md` - Project structure
2. `system-design/fundamentals.md` - Design approach
3. `architecture/fullstack-patterns.md` - Integration patterns
4. `best-practices/code-standards.md` - Coding conventions

## 📚 Tech Stack

- **Backend**: Django 5+, Django REST Framework, Django Channels
- **Frontend**: Next.js 14+, React 18+, TypeScript 5+
- **Database**: PostgreSQL 15+, Redis 7+, Elasticsearch 8+
- **DevOps**: Docker, Kubernetes, GitHub Actions, Prometheus/Grafana
